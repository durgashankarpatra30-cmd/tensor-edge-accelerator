1. S_AXIS Ingress Protocol

  • Dynamic Config (tuser=00): Updates ReLU / LeakyReLU / Linear modes & scaling shift on the fly.
  • Weight Stream (tuser=01): Automatically steers 4 beats into Rows 0, 1, 2, 3 via one-hot decoder.
  • Activation Stream (tuser=10): Pulses core_start for inference execution.

2. M_AXIS Egress Flow Control

  • Registered Outputs: m_axis_tdata and m_axis_tvalid driven by flip-flops for glitch-free bus timing.
  • Backpressure Protection: Holds data completely stable if m_axis_tready = 0.
  • TLAST Frame Demarcation: Asserts m_axis_tlast = 1 on matrix completion for DMA interrupt generation.

3. Bidirectional Throttling

  • Equation: s_axis_tready = !core_busy && (!m_axis_tvalid || m_axis_tready);
  • Zero Overrun: Halts incoming upstream stream if downstream memory is temporarily stalled.
  • Firmware Integration: Compatible with standard Linux/FreeRTOS AXI DMA ring buffers.
