50-Day Tensor Edge Accelerator — Day 4 Hardware Architecture (Ping-Pong True Dual-Port Block RAM)

Port A Signal Path (50 MHz Ingestion)

Ping-Pong Bank Control (Collision Prevention)
Dedicated Block RAM Core (Synchronous 1-Cycle Read)
Circuit Highlights:
  • Physical Address Concatenation: physical_addra = {bank_sel_i, addra[8:0]} and physical_addrb = {~bank_sel_i, addrb[8:0]} prevents address collisions at the silicon level.
  • Dual-Clock Boundaries: Port A operates completely on clka, Port B operates completely on clkb. No cross-clock metastability occurs because each port accesses an isolated bank.
  • Registered Outputs: Data outputs douta and doutb are latched into D-flip-flops on the rising edge of their respective clocks, yielding 1-cycle latency and enabling 250+ MHz fMAX.
