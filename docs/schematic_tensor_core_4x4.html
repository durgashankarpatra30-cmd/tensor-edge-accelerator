1. Input Triangular Skew Buffer

  • Purpose: Synchronizes unskewed parallel input vector with systolic diagonal wavefront.
  • Delays: Row 0: 0 cyc, Row 1: 1 cyc, Row 2: 2 cyc, Row 3: 3 cyc.
  • Silicon Cost: 6 registers total (48 flip-flops).

2. 4x4 Systolic Array

  • Dataflow: Weight-Stationary (WS), Horizontal Act stream, Vertical Psum accumulate.
  • Peak Throughput: 16 MACs/cycle = 2.0 GOPS @ 125 MHz.
  • Accumulation Width: 16-bit signed Q8.8 fixed-point with saturation clamping.

3. Output Deskew & Activation

  • Deskew Delays: Col 0: 3 cyc, Col 1: 2 cyc, Col 2: 1 cyc, Col 3: 0 cyc.
  • Alignment: All 4 columns emerge at the exact same clock tick (Cycle 7).
  • Re-quantization: Clamped INT8 output with Linear, ReLU, or LeakyReLU activation.
