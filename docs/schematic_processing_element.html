Key Architectural Properties:
  • Weight-Stationary Reuse: Weight is loaded once into weight_reg and remains locked, consuming 0 memory bandwidth during continuous streaming inferences.
  • Pipelined Forwarding: Activations hop right on every clock tick (act_out <= act_in), and partial sums hop down on every clock tick (psum_out <= saturated_sum).
  • True Saturation Protection: If intermediate neural network products accumulate beyond signed 16-bit bounds, the 17-bit accumulator clamps to +32767 or -32768 rather than suffering catastrophic wrap-around overflow.
